# 🐍 Python Mini Projects Collection

A collection of simple Python projects including games and utilities, perfect for beginners to practice programming concepts.



## Projects Included

### 1. Password Generator  
Generates a random secure password based on user-defined length and character types.

### 2. Random Number Game  
A guessing game where the player tries to guess a randomly generated number within a certain range.

### 3. Rock, Paper, Scissors Game  
Classic Rock, Paper, Scissors game against the computer with simple text input.

### 4. Treasure Island Game  
An interactive text-based adventure game where you make choices to find the treasure.
